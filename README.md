### 📁 Projetos em Destaque

#### 1. 🕒 **Sistema de Ponto Eletrônico (MVC / PHP)**
Sistema de gestão de horas e controle de funcionários com arquitetura MVC.
- **Features:** Validação com Cerca Virtual (Haversine), captura de selfies, integração com painéis admin, e exportação de relatórios.
- **Tech:** PHP 8, Arquitetura MVC, MySQL/PDO, Bootstrap 5, Fetch API.

#### 2. 🚀 **[Dashboard de Inteligência de Tráfego](https://github.com/Edu4rd0sant/dashboard-trafego-fullstack)**
Sistema de BI interativo com backend serverless para métricas avançadas de anúncios.
- **Features:** Sincronização via API do Meta Ads, interface Dark Mode refinada.
- **Tech:** Next.js 14, React, Tailwind CSS, PostgreSQL, Prisma.

#### 3. 📊 **Dashboard ROAS**
Ferramenta analítica focada em monitoramento financeiro instantâneo.
- **Features:** Cálculo em tempo real do ROAS via processamento de base de dados extraídas do tráfego pago.
- **Tech:** Python, Streamlit, Pandas.

#### 4. 🏠 **Simulador Home Equity**
Painel interativo para cálculo dinâmico e simulação de crédito com garantia de imóvel.
- **Tech:** JavaScript Vanilla, Lógica Financeira, HTML5/CSS3.
